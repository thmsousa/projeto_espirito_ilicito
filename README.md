# ESPÍRITO ILÍCITO - Landing Page Oficial

Landing page promocional (single-page application) para o lançamento do livro **"Espírito Ilícito"** do autor Pablo Costa. O projeto é focado em alta performance e conversão (venda de Ebook Kindle e captação de contato).

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Framework:** Next.js (App Router)
* **Linguagem:** React / TypeScript / JavaScript
* **Estilização:** Sass (SCSS)
* **Ícones:** React Icons
* **Hospedagem Recomendada:** Vercel (Utiliza Static Site Generation - SSG para máxima performance)

## 📦 Como Instalar e Executar (Desenvolvimento)

Para rodar este projeto na sua máquina local, siga os passos abaixo:

1.  **Clone o Repositório:**
    ```bash
    git clone [https://docs.github.com/pt/repositories/creating-and-managing-repositories/quickstart-for-repositories](https://docs.github.com/pt/repositories/creating-and-managing-repositories/quickstart-for-repositories)
    cd projeto-espirito-ilicito
    ```

2.  **Instale as Dependências:**
    ```bash
    npm install
    ```

3.  **Inicie o Servidor de Desenvolvimento:**
    ```bash
    npm run dev
    ```
    O site estará acessível em `http://localhost:3000`.
